What changed in Home Assistant 2026.11

Your copy of the book was written for Home Assistant 2026.9. Release 2026.11 (4 November 2026) changed five things a reader will notice. Each note below says what changed and what to do.

Companion resource for Home Assistant Smart Home for Beginners by Digital Basics Press. Last checked against the official release notes on 10 November 2026.

Get the next notes by email

Home Assistant ships a new release every month. When one changes something the book teaches, we send one short email with the fix. No other mail.

The 25 automations Setup Audit Sheet

1. HACS is now the built-in Marketplace

The book tells you to install a separate tool called HACS to find community integrations, cards and themes. Since release 2026.11 that tool is built into Home Assistant and is called the Marketplace. There is nothing to install first.

  • Open it from Settings > Marketplace.
  • Before your first install, a notice called "Before you install from the Marketplace" appears. Tick I understand the risks and agree. Nothing installs or updates until you do.
  • Find what you want and select Install. An integration goes straight into its setup screens, with no restart.
  • Updates for what you installed appear under Settings > Updates, next to Home Assistant's own updates. Some still need a restart, and a Repair message offers to do it for you.
  • If you used HACS before, Home Assistant moves it over by itself when you update. What you installed stays installed, and your custom repositories carry over.
  • If you are still on 2026.10 or older, update first, or follow the instructions at hacs.xyz.

Everything in the Marketplace is written by independent developers and nobody at the project has checked it for you. Read the project's page and look at when it was last updated. Install one thing at a time and wait a day, so you know what caused a problem. Where another project's instructions say "install through HACS", read that as "the Marketplace".

2. Names on your screen look different

A card or a list now shows the device name followed by the entity name. A thermostat's temperature reading shows as "Thermostat Temperature", and a card can add the area in front. If a name or a screenshot in the book looks different from your screen, this is probably why.

  • Entity IDs did not change, so your automations and YAML keep working.
  • Name the device, not each entity. Call it what it is and where it is, such as "Hallway motion sensor", and put it in an area.
  • Renaming an entity changes only that entity. To change the name everywhere, rename the device.
  • Voice commands keep working: when a displayed name changes, the old name is kept as an alias.
  • Do not rename an entity ID later to match. Automations use the ID, and changing it breaks them.

3. "Invalid client id" when you log in from outside

The login is stricter. The address in your browser now has to match the address Home Assistant sees the request arriving on. This affects people who open Home Assistant through a public IP address, a global IPv6 address, or a raw Tailscale address (100.x.x.x). A domain name, or a normal local address such as 192.168.x.x, works as before, so most readers are not affected.

  • If you see the message, reach Home Assistant through a domain name instead of the raw address.
  • If you use a reverse proxy, add it to the trusted proxies of the HTTP integration.
  • Do not fix this by opening a port on your router. The official remote-access page says that is not secure.

4. Backups to a USB drive

You can now store backups on a disk you plug in. Go to Settings > System > Storage, select Add storage, and choose Local disk. The disk has to be formatted already. Then switch that location on under Locations in your automatic backup settings.

A drive plugged into the same Home Assistant computer is still "the same box". If the box is stolen or burns, the drive goes with it. Keep one copy somewhere else too.

5. Coming on 2 December 2026: "Home Assistant Cloud" becomes "Home Assistant Link"

The optional subscription from Nabu Casa is being renamed. It is the same service with a new name. Where the book says "Home Assistant Cloud", newer versions will say "Home Assistant Link". Menus may show the old name for a while.

Lighting layer

4 automations

1. Hallway light follows motion, with a 2-minute off-delay

What it does: Turns the hallway light on the instant motion is seen, and off automatically once the hallway has been clear of motion for 2 minutes.

The Layer Method note:Layer: Lighting. This is a good first automation to build, full stop. Live with it for about a week before you touch anything else — watch whether 2 minutes is too short (the light keeps snapping off while you're still in the hallway) or too long (it stays on a while after you've left), and adjust the for: value before you add the next lighting automation.

Placeholders to replace: binary_sensor.hallway_motion, light.hallway

alias: "Hallway light follows motion, with a 2-minute off-delay"
id: hallway_motion_light_off_delay
description: "Turns the hallway light on for motion and off 2 minutes after motion clears."
mode: restart
triggers:
  - trigger: state
    entity_id: binary_sensor.hallway_motion
    to: "on"
    id: motion_on
  - trigger: state
    entity_id: binary_sensor.hallway_motion
    to: "off"
    for:
      minutes: 2
    id: motion_off
actions:
  - choose:
      - conditions:
          - condition: trigger
            id: motion_on
        sequence:
          - action: light.turn_on
            target:
              entity_id: light.hallway
      - conditions:
          - condition: trigger
            id: motion_off
        sequence:
          - action: light.turn_off
            target:
              entity_id: light.hallway

Source: State trigger, to:/for:/id: — https://www.home-assistant.io/triggers/state/
Source: Cross-cutting trigger mechanics, trigger id: — https://www.home-assistant.io/docs/automation/trigger/
Source: Triggered by condition (condition: trigger, id:) — https://www.home-assistant.io/docs/scripts/conditions/
Source: choose action — https://www.home-assistant.io/docs/scripts/
Source: light.turn_on / light.turn_off with target: — https://www.home-assistant.io/docs/automation/action/

What it does: Turns on two lights 30 minutes before sunset every day, using Home Assistant's own sunset calculation for your location — no fixed clock time to update with the seasons.

The Layer Method note:Layer: Lighting. Add this only after the motion-light layer above has been running quietly for about a week. Live with the -30 minute offset for a week and see if it feels early or late before adding a third lighting automation.

3. Closet light turns off only after motion is truly gone

What it does: Turns the closet light off 5 minutes after motion clears, instead of the instant the sensor blips clear — the fix for a light that flickers off while you're still standing there.

The Layer Method note:Layer: Lighting. This one exists to teach a single idea: for: is what stops a light from flickering off. Live with it for a week in one room, confirm the flicker is gone, then reuse the same for: pattern anywhere else you saw the same problem — don't add it everywhere on day one.

4. Office motion light: bright by day, dim after dark

What it does: One motion sensor, two behaviors: full brightness during the day, a low dim glow once the sun is down, so the light never blinds you at night.

The Layer Method note:Layer: Lighting. This is a step up from a plain motion light — it adds a condition branch. Only build this once you're completely comfortable with the simple motion-light pattern above; live with the two brightness levels for a week and adjust the dim value before adding more branches to any automation.

Placeholders to replace: binary_sensor.office_motion, light.office

alias: "Office motion light: bright by day, dim after dark"
id: office_motion_light_day_night_brightness
description: "Motion turns the office light on at full brightness by day, dim after dark."
mode: restart
triggers:
  - trigger: state
    entity_id: binary_sensor.office_motion
    to: "on"
actions:
  - if:
      - condition: sun
        after: sunset
        before: sunrise
    then:
      - action: light.turn_on
        target:
          entity_id: light.office
        data:
          brightness: 40
    else:
      - action: light.turn_on
        target:
          entity_id: light.office
        data:
          brightness: 255

Source: State trigger to: "on" — https://www.home-assistant.io/triggers/state/
Source: Sunset/sunrise condition ("When dark") — https://www.home-assistant.io/docs/scripts/conditions/
Source: if/then/else; light.turn_on data.brightness — https://www.home-assistant.io/docs/scripts/

17. Garage door left open: notification with a Close button

What it does: If the garage door has been open for 15 minutes, sends a phone notification with a 'Close Garage' button right on it — tapping the button closes the door without opening the app.

The Layer Method note:Layer: Notifications & Voice. This is the most advanced recipe in this pack — it waits for your button tap and then acts on it. Do not attempt this as your first automation in this layer; build the plain phone-alert recipes first, live with them for a week, then come back to this one.

Placeholders to replace: binary_sensor.garage_door, notify.mobile_app_your_phone, cover.garage_door

alias: "Garage door left open: notification with a Close button"
id: actionable_garage_door_notification
description: "Sends an actionable notification with a Close button if the garage stays open."
mode: restart
triggers:
  - trigger: state
    entity_id: binary_sensor.garage_door
    to: "on"
    for:
      minutes: 15
    id: garage_open_too_long
actions:
  - action: notify.mobile_app_your_phone
    data:
      message: "The garage door has been open for 15 minutes."
      data:
        actions:
          - action: "CLOSE_GARAGE"
            title: "Close Garage"
  - wait_for_trigger:
      - trigger: event
        event_type: mobile_app_notification_action
        event_data:
          action: "CLOSE_GARAGE"
    timeout:
      minutes: 10
  - if:
      - "{{ wait.completed }}"
    then:
      - action: cover.close_cover
        target:
          entity_id: cover.garage_door

24. Goodnight routine: notice if a door is still open

What it does: Runs a goodnight check at 10:30 PM. If the back door is still open, posts an in-app failure notice explaining exactly what wasn't ready, and marks the run as failed so it stands out in Logbook and traces.

The Layer Method note:Layer: Reliability. This is the pattern to copy any time you want an automation to tell you WHY it didn't do what you expected, instead of failing silently. Live with it for a week, then reuse the same if / persistent_notification.create / stop shape for your own routines.

Placeholders to replace: binary_sensor.back_door

alias: "Goodnight routine: notice if a door is still open"
id: goodnight_routine_failure_notice
description: "At 10:30 PM, posts a failure notice if the back door is still open."
mode: single
triggers:
  - trigger: time
    at: "22:30:00"
actions:
  - if:
      - condition: state
        entity_id: binary_sensor.back_door
        state: "on"
    then:
      - action: persistent_notification.create
        data:
          title: "Goodnight routine did not complete"
          message: "The back door is still open, so the goodnight routine stopped early. Close it and run the routine again."
      - stop: "Back door still open"
        error: true
    else:
      - action: persistent_notification.create
        data:
          title: "Goodnight routine complete"
          message: "All checked doors were closed. Goodnight!"
